Aira

我自认为这个名字起得很好，有着 Air，AI，与 “爱” 三层含义。Aira 是一款 macOS 轻量 AI 对话软件，广泛兼容各品牌的 AI API，使用 SwiftUI 编写，支持导入 API、流式对话、思考以及思考深度的调节、Markdown 格式、网页访问 / 连网搜索、长期记忆等功能。软件轻量、简洁、原生，是我目前比较完整的项目。

DmDh-Tools

原本是为自己网站做的简易后台软件，后来逐渐优化，也做了发行版本出来。这是一款运行在 Windows 上的工具软件，使用 Python 和 PySide 开发，主要包含网站状态监测和 OpenCode GUI 两大功能，旨在把一些日常使用的小工具集中起来，提供一个简单、方便的桌面使用体验。
